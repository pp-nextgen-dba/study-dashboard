Chapter roadmap

Learn the logic, not just the labels

ENGLISHA cell is the basic structural and functional unit of life. In this chapter, you will link each organelle to its job, compare animal and plant cells, understand unicellular life and explain how specialised cells form complex organisms.
中文解释细胞是生命的基本结构和功能单位。本章要学会把细胞器与功能联系起来，比较动物和植物细胞，理解单细胞生物如何生存，以及特化细胞如何组成复杂生物。
2.1 Cell organelles→2.2 One-cell life→2.3 Cell specialisation→2.4 Organisation
Big idea / 核心概念: Structure determines function. 结构与功能相适应。 Ask: “What does this cell need to do, and what structures help it do that?”
2.1 · Cell structure and function

Inside a cell / 细胞内部结构

ENGLISHMost organelles have specific roles. Cells coordinate these roles to survive. For example, proteins may be assembled on ribosomes, processed through the rough ER and Golgi apparatus, then delivered in vesicles.
中文解释不同细胞器负责不同工作，并相互配合。例如，核糖体制造蛋白质，粗面内质网参与加工与运输，高尔基体进一步修饰、分类和包装，最后由囊泡运送。

Organelles and their functions / 细胞器功能

Memory chain / 记忆流程: Ribosome (makes protein) → rough ER (processes/transports) → Golgi apparatus (modifies, sorts, packages) → vesicle (delivers).
核糖体（合成）→ 粗面内质网（加工与运输）→ 高尔基体（修饰、分类、包装）→ 囊泡（运送）。

2.2 · Unicellular organisms

One cell does everything / 单细胞完成全部生命活动

ENGLISHAmoeba and Paramecium are unicellular organisms. Their one cell carries out nutrition, movement, gas exchange, excretion, reproduction and response to stimuli. Their structures differ, but both must meet the same life needs.
中文解释变形虫和草履虫都是单细胞生物。一个细胞必须完成摄食、移动、气体交换、排泄、生殖和对刺激作出反应等活动。两者结构不同，但都必须满足生命的基本需要。

Amoeba sp. / 变形虫

Movement: pseudopodia (temporary extensions). / 伪足移动。

Feeding: engulfs food by phagocytosis; forms food vacuoles. / 通过吞噬作用摄食，形成食物液泡。

Respiration: gases diffuse across membrane. / 气体经细胞膜扩散。

Water balance: contractile vacuole removes excess water. / 伸缩泡排出多余水分。

Paramecium sp. / 草履虫

Movement: coordinated beating of cilia. / 纤毛有规律地摆动。

Feeding: cilia sweep food into oral groove. / 纤毛将食物送入口沟。

Respiration: gas exchange by diffusion. / 气体通过扩散交换。

Water balance: contractile vacuoles expel excess water. / 伸缩泡排出多余水分。

Reproduction / 生殖

ENGLISHBoth can reproduce asexually by binary fission under suitable conditions. Paramecium can also undergo conjugation, which exchanges genetic material but is not itself an immediate increase in the number of individuals. Under harsh conditions, some amoebae can form protective cysts; avoid assuming all Amoeba species form spores.
中文解释在适宜环境下，两者可通过二分裂进行无性生殖。草履虫也可进行接合，交换遗传物质，但接合本身不会立即增加个体数量。恶劣环境下某些变形虫会形成保护性包囊，不宜一概说所有变形虫都会形成孢子。
Compare / 比较: Amoeba = pseudopodia + engulfing; Paramecium = cilia + oral groove. / 变形虫＝伪足＋吞噬；草履虫＝纤毛＋口沟。
2.3 · Multicellular organisms

Specialised cells / 特化细胞

ENGLISHCell differentiation is the process by which cells become specialised in structure and function. Different cells use different sets of genes and develop structures suited to their roles. Cells with high energy demand often contain many mitochondria; photosynthetic cells contain many chloroplasts.
中文解释细胞分化是细胞在结构和功能上逐渐特化的过程。不同细胞会表达不同的基因，并形成适合其工作的结构。需要大量能量的细胞通常有较多线粒体；负责光合作用的细胞通常有较多叶绿体。
Specialised cell / 特化细胞Adaptation / 结构特点Why it helps / 功能原因
Muscle cell / 肌肉细胞Many mitochondria / 线粒体多ATP for contraction / 为收缩提供ATP
Sperm cell / 精子Flagellum; many mitochondria in midpiece / 有鞭毛，中段线粒体多Movement toward egg / 游向卵细胞
Palisade mesophyll / 栅栏叶肉细胞Many chloroplasts / 叶绿体多Absorb light for photosynthesis / 吸收光能进行光合作用
Pancreatic secretory cell / 胰腺分泌细胞Abundant rough ER and Golgi / 粗面内质网及高尔基体丰富Make and secrete proteins such as digestive enzymes / 合成和分泌消化酶等蛋白质
Goblet cell / 杯状细胞Developed ER and Golgi / 内质网与高尔基体发达Produce and secrete mucus / 产生和分泌黏液
Liver cell / 肝细胞Abundant smooth ER / 滑面内质网丰富Lipid metabolism and detoxification / 脂质代谢与解毒
Root hair cell / 根毛细胞Long extension / 细长突起Large surface area for absorption / 增大吸收表面积
Xylem vessel / 木质部导管Hollow, lignified walls at maturity / 成熟时中空、木质化细胞壁Water transport and support / 输水和支持
SPM answer pattern / 作答公式: Structural feature → Biological effect → Function.
结构特点 → 产生的作用 → 最终功能。
Example: “A sperm cell contains many mitochondria → produces ATP by respiration → powers movement of its flagellum.”
2.4 · Levels of organisation

From cell to organism / 从细胞到生物体

Cell
细胞→Tissue
组织→Organ
器官→Organ system
器官系统→Organism
生物体
ENGLISHA tissue is a group of similar cells working together. An organ contains different tissues cooperating in a particular function. An organ system contains organs that work together. All systems form the organism.
中文解释组织由执行共同功能的相似细胞组成；器官由多种组织构成并共同完成特定功能；器官系统由多个协作的器官组成；所有系统共同维持整个生物体的生命活动。
Example / 例子：Human digestion 人体消化

Epithelial cell → epithelial tissue → small intestine → digestive system → human.

上皮细胞 → 上皮组织 → 小肠 → 消化系统 → 人体。

The small intestine also contains smooth muscle, connective and nervous tissues. / 小肠也含平滑肌、结缔组织和神经组织。

Common trap / 常见错误: A tissue is not the same as an organ. An organ is made of multiple tissue types. / 组织不等于器官；器官由多种组织构成。
SPM examination clinic

How to earn marks / 如何拿分

State / 写出

Give a direct fact. Example: “Name the organelle that synthesises proteins.” → Ribosome.

直接写答案：合成蛋白质的细胞器＝核糖体。

Explain / 解释

Link cause to effect. “Why does a muscle cell contain many mitochondria?” → To produce more ATP for muscle contraction.

要说明因果关系：线粒体多 → 产生ATP → 支持肌肉收缩。

Compare / 比较

State both sides: “Plant cells have a cellulose cell wall whereas animal cells do not.”

写出双方差异：植物细胞有纤维素细胞壁，而动物细胞没有。

Predict / 预测

Use the function to predict a consequence. “If mitochondria are damaged, ATP production decreases, so energy-dependent processes may slow.”

由功能推断结果：线粒体受损 → ATP减少 → 需能量的活动减慢。

Worked structured question / 结构题示范

Q: A pancreatic cell secretes large amounts of digestive enzymes. Explain why it contains abundant rough ER and Golgi apparatus. [3 marks / 3分]

Model answer: (1) Ribosomes on rough ER synthesise protein enzymes. (2) Rough ER helps process and transport these proteins. (3) Golgi apparatus modifies, sorts and packages them into vesicles for secretion.

中文理解：（1）粗面内质网上的核糖体合成蛋白质酶；（2）粗面内质网协助加工和运输；（3）高尔基体修饰、分类并包装成囊泡以便分泌。

Illustrative marking points for practice, not an official marking scheme. / 示范评分点，非官方评分标准。
