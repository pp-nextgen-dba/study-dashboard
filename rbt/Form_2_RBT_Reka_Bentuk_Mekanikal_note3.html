📘 Definisi / Definition / 定义
Reka bentuk mekanikal ialah proses mereka bentuk produk menggunakan komponen mekanikal untuk memindahkan daya dan gerakan supaya produk berfungsi dengan selamat dan cekap.
Mechanical design uses mechanical components to transfer force and motion so a product works safely and efficiently.
机械设计 利用机械组件传递力和运动，使产品能够安全、高效运作。
Kata kunci / Keywords / 关键词: daya, gerakan, komponen, fungsi, sistem, penambahbaikan.
🧩 Komponen Mekanikal / Mechanical Components / 机械组件
⚙️

Gear / 齿轮

Putaran / Rotation / 旋转
Memindahkan gerakan putaran serta menukar kelajuan atau arah.
Transfers rotational motion and changes speed or direction.
传递旋转运动，并改变速度或方向。
Contoh: jam, mesin, basikal / clock, machine, bicycle / 时钟、机器、自行车
⛓️

Rantai / Chain / 链条

Kuasa / Power / 动力
Menghantar kuasa antara sproket yang berjauhan.
Transmits power between distant sprockets.
在相距较远的链轮之间传递动力。
Contoh: basikal / bicycle / 自行车
🛞

Takal / Pulley / 滑轮

Mengangkat / Lifting / 起重
Menukar arah daya dan memudahkan kerja mengangkat.
Changes force direction and makes lifting easier.
改变施力方向，使起重更容易。
Contoh: tiang bendera, kren / flagpole, crane / 旗杆、起重机
🔄

Tali sawat / Belt / 皮带

Lancar / Smooth / 平稳
Memindahkan kuasa dengan lancar antara dua aci.
Transfers power smoothly between two shafts.
在两根轴之间平稳传递动力。
Contoh: mesin jahit / sewing machine / 缝纫机
⭕

Galas bebola / Ball bearing / 滚珠轴承

Kurang geseran / Less friction / 减少摩擦
Mengurangkan geseran dan melancarkan putaran.
Reduces friction and allows smooth rotation.
减少摩擦，使旋转更顺畅。
Contoh: roda basikal, kipas / bicycle wheel, fan / 自行车轮、风扇
🔗

Pautan / Linkage / 连杆机构

Penghubung / Connector / 连接
Menghubungkan komponen dan menukar jenis gerakan.
Connects components and changes the type of motion.
连接组件，并改变运动方式。
Contoh: ampaian lipat, pengelap cermin / folding rack, wiper / 折叠衣架、雨刷
⚖️

Tuas / Lever / 杠杆

Daya / Force / 力
Menggandakan daya atau menukar arah daya.
Multiplies force or changes force direction.
放大作用力或改变施力方向。
Contoh: gunting, stapler, kereta sorong / scissors, stapler, wheelbarrow / 剪刀、订书机、手推车
↔️

Gelongsor / Slider / 滑块

Linear / 直线运动
Menghasilkan gerakan linear yang lancar.
Produces smooth linear movement.
产生平稳的直线运动。
Contoh: laci, lampu basikal / drawer, bicycle lamp / 抽屉、自行车灯
⚙️ Jenis Gear / Types of Gears / 齿轮种类
1
⚙️

Gear heliks / Helical gear / 斜齿轮

Gigi serong; lebih senyap dan sesuai untuk kelajuan tinggi.

Slanted teeth; quieter at higher speed.

齿面倾斜，运转较安静，适合高速。

2
🪱

Gear belitan / Worm gear / 蜗轮蜗杆

Skru dan gear; memberikan nisbah gear yang besar.

A screw and gear provide a large gear ratio.

由蜗杆和齿轮组成，提供较大传动比。

3
🔺

Gear serong / Bevel gear / 锥齿轮

Memindahkan gerakan antara dua aci bersilang, biasanya 90°.

Transfers motion between intersecting shafts, usually at 90°.

用于相交轴之间传递运动，通常为 90°。

4
📏

Rak dan pinan / Rack and pinion / 齿条与小齿轮

Menukar gerakan putaran kepada gerakan linear.

Changes rotational motion into linear motion.

把旋转运动变为直线运动。

5
⭕⚙️

Gear dalaman / Internal gear / 内齿轮

Gigi gear berada di bahagian dalam gear besar.

The teeth are inside the larger gear.

齿位于大齿轮内部。

🚲 Bagaimana Sistem Mekanikal Berfungsi? / How It Works / 机械系统如何运作
🚲

Basikal / Bicycle / 自行车

Pedal → gear hadapan → rantai → gear belakang → roda belakang

踏板 → 前齿轮 → 链条 → 后齿轮 → 后轮

  1. Pedal / 踏板: memusing gear hadapan / rotates front gear / 带动前齿轮。
  2. Rantai dan gear / 链条与齿轮: menghantar kuasa / transmit power / 传递动力。
  3. Roda / 车轮: menggerakkan basikal / moves the bicycle / 推动自行车。
  4. Hendal / 车把: mengawal arah / controls direction / 控制方向。
  5. Brek / 刹车: memperlahankan atau berhenti / slows or stops / 减速或停止。

📝 Teknik Menjawab Peperiksaan / Exam Tips / 考试技巧

1. Kenal pasti dengan tepat

Lihat bentuk dan fungsi pada rajah.

Identify it from shape and function.

根据形状和功能判断组件。

2. Gunakan kata kerja fungsi

Memindahkan, mengurangkan, menukar, menghubungkan.

Transfer, reduce, change, connect.

传递、减少、改变、连接。

3. Beri contoh produk yang sesuai

Contoh mesti benar-benar menggunakan komponen tersebut.

The example must really use that component.

产品例子必须确实使用该组件。

4. Hafal enam langkah

Lakaran → sedia bahan → hasil → pasang → uji → kemasan.

Sketch → prepare → fabricate → assemble → test → finish.

草图 → 准备 → 制作 → 组装 → 测试 → 完成。

5. Jawab ikut markah

1 markah = 1 fakta
2 markah = 2 isi
4 markah = 4 isi atau 2 isi dengan huraian

6. Gunakan istilah yang betul

Pautan, tuas, gelongsor, gear serong, gear belitan, galas bebola.

Linkage, lever, slider, bevel gear, worm gear, ball bearing.

连杆、杠杆、滑块、锥齿轮、蜗轮蜗杆、滚珠轴承。
