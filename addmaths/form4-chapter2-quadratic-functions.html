Quadratic Functions

二次函数

One curve, four questions: what are its roots, what shape does it draw, where's its lowest/highest point, and where is it positive or negative? Answer those and this chapter is done.

同一条曲线，四个问题：它的根是什么、图像长什么样、最低/最高点在哪、在哪个范围为正或为负？把这四个问题弄懂，这一章就掌握了。

Roots are where the curve crosses the x-axis, the turning point is its lowest (or highest) value, and the sign of f(x) flips exactly at the roots — that single picture is the whole chapter.

根是曲线与x轴相交之处，转折点是它的最低（或最高）值，而 f(x) 的正负恰好在根处发生转变——这一张图就是整章的核心。

2.1

Quadratic Equations

二次方程

A quadratic equation has the form ax² + bx + c = 0, where a ≠ 0. Solving it means finding the value(s) of x that make it true — these values are called the roots.

二次方程的一般形式为 ax² + bx + c = 0（a ≠ 0）。解方程就是求出使等式成立的 x 值，这些值称为方程的根。

General Form

一般式

ax² + bx + c = 0, a ≠ 0

a, b, c are constants. The a ≠ 0 condition is what makes it "quadratic" and not linear.

a、b、c 为常数。a ≠ 0 是"二次"方程区别于一次方程的关键条件。

Solving by Factorisation

因式分解法

ax²+bx+c = a(x−α)(x−β) = 0

Works when the expression factorises neatly — set each bracket to zero.

当表达式能整齐地分解因式时使用——令每个括号分别等于零。

The Quadratic Formula

求根公式

x = (−b ± √(b²−4ac)) / 2a

Always works, even when factorisation doesn't. Memorise this one exactly.

无论能否因式分解都适用，必须准确背熟。

⚠️
Common trap: before reading off a, b, c, always rearrange the equation to equal zero first (e.g. 2x² = 5x + 3 → 2x² − 5x − 3 = 0). Plugging in a, b, c from the un-rearranged form gives the wrong roots. 常见陷阱：代入 a、b、c 之前，必须先把方程移项使其等于零（例如 2x² = 5x + 3 → 2x² − 5x − 3 = 0）。若直接用未移项的形式代入，会得到错误的根。
Worked Example
例题
Solve 2x² − 5x − 3 = 0
解方程 2x² − 5x − 3 = 0
a=2, b=−5, c=−3
x = (5 ± √(25 + 24)) / 4  ← substitute into the formula
x = (5 ± 7) / 4
x = 3 or x = −1/2
Memory hook: "Zero on one side, then decide." Always clear the equation to = 0 first, then choose factorisation if it looks clean, or the formula if it doesn't. 记忆口诀："先移项等于零，再决定用哪招。"先把方程化为等于零，看起来能整除就用因式分解，否则直接套公式。

2.2

Types of Roots & the Discriminant

根的类型与判别式

You can tell what kind of roots a quadratic has without solving it, just by checking the sign of b² − 4ac — this expression is called the discriminant.

不需要真正解方程，只要检查 b² − 4ac 的正负，就能判断二次方程的根属于哪一种类型——这个表达式称为判别式。

Two Different Real Roots

两个不同实根

b² − 4ac > 0

The curve crosses the x-axis at two distinct points.

曲线与x轴有两个不同的交点。

Two Equal Real Roots

两个相等实根

b² − 4ac = 0

The curve just touches the x-axis at one point (the turning point sits on the axis).

曲线恰好与x轴相切于一点（转折点正好落在x轴上）。

No Real Roots

无实根

b² − 4ac < 0

The curve never touches the x-axis at all.

曲线完全不与x轴相交。

⚠️
Common trap: the discriminant is b² − 4ac, not (b − 4ac)² or b² + 4ac. Also, "b² − 4ac ≥ 0" (not just > 0) is the condition often asked for "real roots" — it includes the equal-roots case. 常见陷阱：判别式是 b² − 4ac，不是 (b − 4ac)² 或 b² + 4ac。此外，题目问"有实根"时条件是 b² − 4ac ≥ 0（不只是 > 0），因为它包含相等实根的情况。
Worked Example
例题
Find the range of values of k for which x² + kx + 9 = 0 has equal roots.
求 k 的范围，使方程 x² + kx + 9 = 0 有两个相等实根。
Equal roots ⟹ b² − 4ac = 0  ← the condition to use
k² − 4(1)(9) = 0
k² = 36
k = ±6
Memory hook: "Positive splits, zero kisses, negative misses." b²−4ac > 0 → the curve splits the axis at two points; = 0 → it just kisses the axis once; < 0 → it misses the axis entirely. 记忆口诀："大于零两分，等于零一碰，小于零不相逢。" b²−4ac > 0 → 与x轴相交两点；= 0 → 恰好相切一点；< 0 → 完全不相交。

Quick Check

快速自测

x² − 4x + 4 = 0 has what type of roots?
2x² + 3x + 5 = 0 has what type of roots?
2.3

Graphs of Quadratic Functions

二次函数的图像

Every quadratic function f(x) = ax² + bx + c draws a curve called a parabola. Rewriting it as a(x−h)² + k instantly reveals its turning point and shape — this is "completing the square."

每个二次函数 f(x) = ax² + bx + c 的图像都是一条抛物线。把它改写成 a(x−h)² + k 的形式，就能立刻看出转折点与图像形状——这就是"配方法"。

Completed-Square Form

配方式

f(x) = a(x − h)² + k

Turning point is (h, k). Axis of symmetry is the line x = h.

转折点为 (h, k)，对称轴为直线 x = h。

Shape from the Sign of a

由 a 的正负判断形状

a > 0 → shape ∪, minimum value k
a < 0 → shape ∩, maximum value k

Only the sign of a decides whether the curve opens upward or downward.

只有 a 的正负决定图像开口向上还是向下。

Completing the Square

配方法步骤

ax²+bx+c = a[(x + b/2a)² − (b/2a)²] + c

Factor out a from the x² and x terms, then add/subtract (half the x-coefficient)².

先把 x² 与 x 项提出公因数 a，再加减"x系数一半的平方"来配方。

⚠️
Common trap: in f(x) = a(x−h)² + k, the turning point x-coordinate is h, not −h — watch the sign inside the bracket. E.g. f(x)=2(x−2)²−5 has turning point (2, −5), not (−2, −5). 常见陷阱：在 f(x) = a(x−h)² + k 中，转折点的 x 坐标是 h，不是 −h——注意括号内的正负号。例如 f(x)=2(x−2)²−5 的转折点是 (2, −5)，不是 (−2, −5)。
Worked Example
例题
Express f(x) = 2x² − 8x + 3 in the form a(x−h)² + k, and state its minimum value.
把 f(x) = 2x² − 8x + 3 化为 a(x−h)² + k 的形式，并求其最小值。
f(x) = 2(x² − 4x) + 3  ← factor out a = 2
= 2[(x − 2)² − 4] + 3  ← half of −4 is −2, squared is 4
= 2(x − 2)² − 8 + 3
= 2(x − 2)² − 5
a = 2 > 0 ⟹ minimum value = −5 at x = 2
Memory hook: "Smiley face (∪) → lowest point. Frowny face (∩) → highest point." a > 0 smiles upward and has a minimum; a < 0 frowns downward and has a maximum. 记忆口诀："笑脸（∪）→ 最低点；哭脸（∩）→ 最高点。" a > 0 开口向上如笑脸，有最小值；a < 0 开口向下如哭脸，有最大值。

快速自测

2.4

Quadratic Inequalities

二次不等式

A quadratic inequality asks: for what values of x is ax² + bx + c positive, or negative? Find the roots, sketch the shape, then read the answer straight off the picture.

二次不等式问的是：x 取哪些值时 ax² + bx + c 为正、或为负？先求出根，画出图像形状，再直接从图上读出答案。

Step-by-Step Method

解题步骤

1. Find the roots α, β
2. Sketch the ∪ or ∩ shape
3. Read off the region

Sketching, not solving algebraically, is the reliable way to avoid sign mistakes.

画草图而非纯代数运算，是避免正负号出错的可靠方法。

"Between" or "Outside" the Roots

"根之间"或"根之外"

a > 0, f(x) < 0 → α < x < β
a > 0, f(x) > 0 → x < α or x > β

For a ∪ shape: below zero happens between the roots, above zero happens outside them.

对于∪形图像：曲线在根之间为负，在根之外为正。

⚠️
Common trap: never multiply/divide a quadratic inequality by a negative number without flipping the sign — and never treat (x−α)(x−β) < 0 the same way you'd solve an equation. Sketch it; don't just "cancel" the brackets. 常见陷阱：二次不等式两边乘除负数时必须翻转不等号；(x−α)(x−β) < 0 不能像解方程那样直接"消去"括号——务必画图判断。
Worked Example
例题
Solve x² − x − 6 < 0
解不等式 x² − x − 6 < 0
(x − 3)(x + 2) < 0  ← factorise first
roots: x = 3, x = −2
a = 1 > 0 → shape ∪, so f(x) < 0 between the roots
−2 < x < 3
Memory hook: "∪ shape: negative in the middle, positive on the outside." Sketch the ∪, mark the two roots on the x-axis, and the answer is just which part of the sketch sits above or below the axis. 记忆口诀："∪形：中间为负，两侧为正。"画出∪形，把两个根标在x轴上，答案就是草图中哪一段在x轴上方或下方。

Quick Check

快速自测

(x − 1)(x − 5) > 0, a > 0 → solution is?
x² ≤ 9 → solution is?
