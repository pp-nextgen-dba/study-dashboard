Indices, Surds & Logarithms

指数、根式与对数

Three topics, one idea: they're all different views of the same relationship — a base, a power, and a result. Master how to move between them and this chapter falls into place.

三个主题，一个核心概念：它们都在描述同一种关系——底数、指数与结果。学会在三者之间自由转换，这一章就迎刃而解。

Raising to a power, taking a root, and taking a logarithm are three moves on the same triangle of numbers — a surd undoes a power, a log finds the missing power.

乘方、开根、取对数其实是同一组数字关系的三种表达方式——根式是乘方的逆运算，对数则是用来求"未知的指数"。

4.1

Laws of Indices

指数定律

Indices (powers) tell you how many times a base is multiplied by itself. Every law below is just a shortcut for that repeated multiplication.

指数（乘方）表示底数自乘的次数。以下所有定律都只是"重复相乘"的简便写法。

Same Base

同底数

aᵐ × aⁿ = aᵐ⁺ⁿ
aᵐ ÷ aⁿ = aᵐ⁻ⁿ
(aᵐ)ⁿ = aᵐⁿ

Same Index

同指数

aᵐ × bᵐ = (ab)ᵐ
aᵐ ÷ bᵐ = (a/b)ᵐ

Zero, Negative & Fractional

零、负与分数指数

a⁰ = 1
a⁻ⁿ = 1/aⁿ
a^(1/n) = ⁿ√a
⚠️
Common trap: 2⁴ × 2² ≠ 4⁶, and a⁻ⁿ ≠ −1/aⁿ. Indices only add/subtract when the base is the same number — never combine different bases by adding powers. 常见陷阱：2⁴ × 2² ≠ 4⁶，a⁻ⁿ ≠ −1/aⁿ。只有底数相同时指数才能相加减——底数不同绝不能把指数直接相加。
Worked Example
例题
Simplify 16^(3/4) m⁵n⁸ ÷ m⁹n⁶
化简 16^(3/4) m⁵n⁸ ÷ m⁹n⁶
= (2⁴)^(3/4) m⁵⁻⁹ n⁸⁻⁶  ← convert 16 to base 2, subtract indices
= 2³ m⁻⁴ n²
= 8n²/m⁴  ← a⁻ⁿ = 1/aⁿ
Memory hook: "Same base → add/subtract the roof. Same roof → multiply/divide the floor." Picture the index as a little roof sitting on top of the base. 记忆口诀："底同加减头上小数；头同则把地基相乘除。"把指数想象成底数头顶上的小屋顶。

4.2

Surds

根式

A surd is a root that can't be simplified into an exact number — like √2 or √5. Numbers split into rational (fractions, terminating/recurring decimals) and irrational (surds, π) — this section is about handling the irrational ones cleanly.

根式是无法化成精确数值的方根，例如 √2、√5。数分为有理数（分数、有限或循环小数）与无理数（根式、π）——本节专门处理无理数的运算。

Simplifying Surds

化简根式

√a × √b = √(ab)
√a ÷ √b = √(a/b)

Break the number under the root into a perfect square × remainder.

把根号下的数拆成"完全平方数 × 其余因数"。

Rationalising Denominators

分母有理化

1/√a × √a/√a = √a/a
(a+√b)(a−√b) = a²−b

Multiply top and bottom by the conjugate to remove the surd from the denominator.

分子分母同乘以"共轭根式"，即可消去分母中的根号。

⚠️
Common trap: √a + √b ≠ √(a+b), and √a − √b ≠ √(a−b). Addition/subtraction of surds needs a common surd part — you can't merge them under one root. 常见陷阱：√a + √b ≠ √(a+b)，√a − √b ≠ √(a−b)。根式相加减必须有相同的根式部分，不能直接合并到同一个根号里。
Worked Example
例题
Rationalise 5/(√7+1) + 5/(√7−1)
化简 5/(√7+1) + 5/(√7−1)
= [5(√7−1) + 5(√7+1)] / [(√7+1)(√7−1)]
= (5√7 − 5 + 5√7 + 5) / (7 − 1)
= 10√7 / 6
= 5√7 / 3
Memory hook: "Whatever's stuck under the root, kick it out the back door — multiply by its conjugate twin." A conjugate flips the sign in the middle: (a+√b) ↔ (a−√b). 记忆口诀："根号赖着不肯走，乘上'孪生共轭'就赶走。"共轭根式只是把中间的正负号反过来：(a+√b) ↔ (a−√b)。

4.3

Logarithms

对数

A logarithm answers one question: "what power do I need?" It's the exact reverse of an index — if aˣ = N, then the log form just isolates x.

对数只回答一个问题："需要多少次方？"它正是指数的逆运算——若 aˣ = N，对数形式就是把 x 单独解出来。

Index ⇔ Log Form

指数式与对数式互换

N = aˣ ⇔ logₐN = x

Index form → base stays as the base, power moves out. Log form → answer is the power itself.

指数式：底数依然是底数，指数才是重点；对数式：答案就是那个指数。

Key Values

关键值

logₐ1 = 0
logₐa = 1

log₈0, log₁N and log with a negative number are all undefined.

底数为0、1的对数以及负数的对数皆无定义。

Product / Quotient / Power Laws

积、商、幂法则

logₐxy = logₐx + logₐy
logₐ(x/y) = logₐx − logₐy
logₐxⁿ = n·logₐx

Change of Base

换底公式

logₐb = log꜀b / log꜀a
logₐb = 1 / log_b a

Use this whenever two logs in a question don't share the same base.

当题目中两个对数底数不同时，用换底公式统一底数。

⚠️
Common trap: logₐ(x+y) ≠ logₐx + logₐy. The product law needs a multiplication inside the log, not addition. Also logₐx − logₐy ≠ logₐ(x−y). 常见陷阱：logₐ(x+y) ≠ logₐx + logₐy。积法则要求括号内是相乘，而不是相加；同样 logₐx − logₐy ≠ logₐ(x−y)。
Worked Example
例题
Given log₃2 = p and log₃5 = q, express log₃3.6 in terms of p and/or q.
已知 log₃2 = p，log₃5 = q，用 p 和/或 q 表示 log₃3.6
3.6 = 18/5 = (2×3²)/5
log₃3.6 = log₃2 + log₃3² − log₃5
= log₃2 + 2 − log₃5
= p + 2 − q
Memory hook: "Multiply inside → add outside. Divide inside → subtract outside. Power inside → the power jumps out front." Log laws mirror index laws exactly, because a log is an index in disguise. 记忆口诀："括号里相乘 → 外面相加；括号里相除 → 外面相减；括号里有指数 → 指数跳到前面来。"对数法则其实就是指数法则的另一副面孔。
